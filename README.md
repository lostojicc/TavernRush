# 🍺 Medieval Tavern VR (Google Cardboard)

A mobile VR experience built in Unity where players act as a tavern server, pouring and delivering drinks using gaze-based controls.

<img width="1201" height="612" alt="image" src="https://github.com/user-attachments/assets/636e876b-0688-4896-81e1-f4be98430ad1" />

## 🎯 Overview
Explores core VR interaction and locomotion systems in a constrained mobile environment, focusing on intuitive, controller-free gameplay.

## 🧰 Tech Stack
- Unity (C#)
- Google Cardboard XR Plugin
- Android (mobile VR)

## 🚀 Features
- Object interactions: pick up, fill, empty, carry, and place mugs  
- Gaze-based movement: look-to-walk and ladder climbing  
- Future update: Task-driven gameplay in an immersive medieval tavern setting  

## ▶️ Run
1. Clone the repo  
2. Open in Unity  
3. Build & run on an Android device
